
FUNCTIONALITY
"buildGNCav4trdwi_combo" constructs trace-DWI series-specific b-corrector maps 
from system trace-average corrector "CMAP.cav" defined within characterstic radius "R"
in magnet frame for trace-DWI in image frame

PREREQUISITES
(1) "ExamSeries" structure for the exam-DICOM DWI pre-generated by 
"scaninfo_combo.p" loaded into Matlab workspace. DWI series should
contain three orthogonal directions or trace for all b-values.
(2) "CMAP" structure with a "cav" field for system trace-average corrector map  
in magnet frame, e.g., pre-generated by "gnlCorfTrVecN" with system "Lxyz" 
over "R" = full sys char. radius (e.g., pre-loaded to workspace from saved mat-file)
(3) Characteristic system diameter ("sysD") used for GNL tensor (e.g., 2*R from
gradient SPH coefficient tables, or gradient field MHDs.)
(4) "build_mhd_combo.p" placed in Matlab path.


INPUT
serinf - "ExamSeries(index)" structure for the corresponding DWI series (created by "scaninfo_combo")
 	If series "index" is omitted, will prompt for series number (from "scaninfo.txt" catalogue)
cmap - 3D "dir-average" master trace-corrector map "CMAP.cav(R)" structure in magnet frame
	dim1=RL, dim2=AP, dim3=SI (e.g., pre-loaded to workspace from saved mat-file)
fovc - [FOVrl, FOVap, FOVsi] diameter (mm) of GNL tensor grid (e.g., from MHD or system SPH file)
	 When single number is provided, will assume same diameter along RL,AP,SI

OUTPUT
corim - structure of 3D corrector maps in DWI image space for trace ("corim.cav")
	(NOTE: ignore directional correctors "corim.cg1", "corim.cg2", "corim.cg3") 
	This structure is also saved in "di##..s#_CMAPs.mat" along with the "np" structure 
	of the corresponding DWI series meta-data. MHD files are saved for each individual 
	gradient correction map and labeled accordinly. 

USAGE
>> corim = buildGNCav4trdwi(serinf(indx), cmap, fovc); % will promot to provide series number
						   % from "scaninfo.txt" if "indx" omitted

NOTE1: If called without output assignment (=), the resulting  "corim" structure can be loaded 
from ".._CMAPs.mat"
NOTE2: function uses DICOM LPS convention and 3D "cubic spline" interpolation
       for convertion from magnet-frame to image-frame grid

All output 3D corrector maps may be explored in Matlab or viewed as MHDs.
The output correctors have pixel-by-pixel correspondence to acquired DWI DICOM
